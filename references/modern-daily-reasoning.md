# Modern Daily Reasoning

本文件规定日运解读如何从传统命理模型走向现代生活语境。目标不是把八字包装成科学预测，而是让每条建议都能说清楚：命理信号是什么、它在传统体系里意味着什么、现实中可能对应哪类机制、用户可以如何行动。

## 1. Four-Layer Reasoning

每个重要判断必须区分四层，不能跳步：

1. **事实层**：已经核实的数据，例如四柱、流年/流月/流日、干支关系、用户明确提供的日程和目标。
2. **命理解释层**：传统体系如何解释这些信号。可以引用 A/B/C，但只把它作为传统模型内部的解释。
3. **现实假设层**：把象意转译为现代生活中的可能机制，例如任务负荷、沟通成本、资源分配、规则压力、协作竞争、信息处理或情绪反应。必须用“可能/倾向/如果……则……”表达；没有用户情境支撑时，标注为待验证假设。
4. **行动层**：根据用户目标、成本、风险、可逆性和外部条件，给出实际可执行的选择。

标准推理链：

`命理信号 → 传统象意 → 现实机制假设 → 场景条件核对 → 行动建议`

任何一步缺少依据，都要降低结论力度，不得用更多古籍引用填补现实信息的空缺。

## 2. Translate Traditional Terms Into Modern Language

十神是传统分类工具，不是现代心理学人格类型，也不是现实事件的直接预告。优先解释为“当天值得留意的功能主题”：

| 传统概念 | 现代语境下可讨论的主题 | 不允许直接断言 |
|---|---|---|
| 比肩、劫财 | 同辈协作、竞争、资源共享、边界与自主性 | 一定破财、有人争夺资源 |
| 食神、伤官 | 表达、创作、输出、产品交付、观点表达、规则摩擦 | 一定有灵感、一定口舌是非 |
| 正财、偏财 | 预算、交易、收益成本、资源调度、机会评估 | 一定进账、一定破财 |
| 正官、七杀 | 责任、制度、审批、期限、绩效压力、权责关系 | 一定升职、一定被批评或遇到小人 |
| 正印、偏印 | 学习、研究、信息吸收、支持系统、复盘与准备 | 一定有贵人、一定适合闭门不出 |

其他传统术语也必须先解释其在命理系统中的含义，再转译为可观察的现代主题。不得将“某十神出现”写成“某个具体的人或事件一定出现”。

## 3. Event Reasoning: Analyze the Actual Thing the User Wants to Do

当用户问“今天适不适合 X”时，先把 X 拆成现实决策，不要先搜一个古籍里的“宜/忌”句子。

依次检查：

- **目标**：用户希望通过这件事得到什么结果？今天必须完成，还是可以选择时间？
- **任务性质**：这是创造/表达、沟通/协商、学习/研究、交易/付款、签约/承诺、出行/执行，还是休息/恢复？
- **外部条件**：对方是否可约、材料是否齐全、信息是否充分、资源是否到位、是否有截止时间？
- **代价与风险**：失败的成本是什么？是否涉及金钱、健康、法律责任、重要关系或不可逆承诺？
- **可逆性**：能否先试运行、先沟通、先提交草案、先做小额验证，而不是一次性押注？
- **用户状态**：只有用户主动提供或明确授权读取的状态信息才可纳入，不得凭八字推断其当天真实睡眠、身体状况、情绪或工作安排。

### Decision Rule

- 如果现实条件明确支持执行，不能仅因传统象意不佳就劝用户放弃；可以把命理提示转成风险控制动作。
- 如果现实条件明显不支持执行，不得因为“日运吉”而鼓励用户忽视期限、准备不足、现金流或安全问题。
- 如果事情可逆、成本低，优先建议小步试行、收集反馈。
- 如果事情高成本、不可逆或涉及健康/法律/投资等专业领域，现实证据与专业意见优先；八字只能作为非决定性的文化参考。
- 如果关键现实信息缺失，给出条件分支，或只问一个会实质改变建议的问题。不要假装已经知道用户的现实处境。

## 4. Turn “Yi / Ji” Into Concrete Behaviors

不要只写“宜沟通、忌争执”“宜求财、忌投资”。要把它们改写成具体行为：

- 空泛：宜沟通。
- 可执行：适合先对齐目标、确认分工和截止时间；涉及责任归属时，把口头共识补成文字。

- 空泛：忌求财。
- 可执行：涉及付款或报价时，先核对总成本、退款条件和隐藏费用；不因短期情绪或所谓“财运”做冲动承诺。

- 空泛：宜学习。
- 可执行：适合集中处理一项需要理解和整理的信息任务；把学习目标缩小到一个可完成的章节或问题。

“宜”描述更值得优先尝试的行为；“忌”描述更值得增加检查、延迟承诺或降低风险的行为。它们不是命令，也不应制造恐惧。

## 5. How to Use Daily Luck Signals

- **流日**：作为当天主题的主要象征输入。解释它与日主、命局关键位置的关系；只有在能说明作用路径时，才提冲合刑害。
- **流月**：作为阶段性环境背景，说明它如何强化、缓和或改变流日主题。
- **流年**：作为较长期的背景，不要让年度判断盖过当天具体条件。
- **伏吟、反吟、刑冲合害**：先说明发生在哪两组干支、作用到命局哪个位置，再讨论可能的主题；不得仅凭术语直接预测争吵、疾病、破财、事故或关系变化。
- **喜忌与用神**：只能说明传统体系内部的倾向，不得把“喜某五行”机械映射成现实中的颜色、方位、消费、投资或职业选择。

## 6. Specific-Question Output Pattern

用户问“今天适不适合做 X”时，优先按下面结构回答：

1. **直接结论**：适合 / 可以但需满足条件 / 不建议仅凭当前信息决定。
2. **命理线索**：只挑 1-3 个最相关的信号，解释其传统含义。
3. **现实推理**：写清楚这些信号可能对应的现实机制，以及目前已知/未知的场景条件。
4. **更稳妥的做法**：给出今天可以执行的步骤、检查项或替代方案。
5. **判断边界**：说明什么新信息会改变结论。

如果用户只问“今日运势”，用 2-3 个主题概括即可，不要为了显得丰富而编造具体事件。若用户没有提供具体安排，建议应保持通用、低风险、可逆。

## 7. Calibration and Language

推荐表达：
- “从传统命理角度，这组信号更偏向……”
- “转译到现实场景，可以把它理解为……”
- “如果你今天确实有……安排，建议……”
- “这是一条值得留意的假设，不代表事件一定发生。”
- “现实条件比日运标签更重要。”

避免表达：
- “今天一定会……”
- “你今天会遇到……”
- “古书说了，所以今天不能……”
- “这是凶日，千万不要……”
- “你的命局决定你不适合……”

禁止把健康、财务、法律、职业等重大结果归因于八字，也不得用命理术语代替专业评估。

## 8. Quality Checklist

输出前逐项检查：

- [ ] 是否区分了盘面事实、传统解释、现实假设和行动建议？
- [ ] 是否解释了命理信号到现实机制之间的推理桥梁？
- [ ] 是否避免把十神、神煞或冲合直接写成确定事件？
- [ ] 是否考虑用户真正要做的事情、目标、资源、成本和可逆性？
- [ ] “宜/忌”是否具体到行为，而不是只给吉凶标签？
- [ ] 是否明确指出未知条件和结论边界？
- [ ] 是否避免让古籍引用替代现实逻辑？
